# C++ 작성 기준

프로젝트 루트의 `AGENTS.md`와 `.clang-format`을 기준으로 한다.

C++20, Objective-C++, UTF-8, 공백 4칸, 최대 120열을 사용한다. `.clang-format`이 서식 기준이다.

- 함수는 CamelCase, 멤버는 접미사 `_` 없이 쓴다. 필요한 경우 `this->member`를 사용한다.
- 객체 초기화는 `{}`를 사용한다. 벡터 크기는 `resize` 등으로 initializer_list와 혼동하지 않게 한다.
- 한 줄에 한 statement를 쓰고 동작 단위 전후에 빈 줄을 둔다.
- 클래스·함수·여러 문장 제어문의 중괄호는 다음 줄, namespace·람다는 같은 줄에 둔다.
- 단일 문장 제어문은 스코프·수명·else 연결을 해치지 않으면 중괄호를 생략한다.
- 접근 지정자는 클래스 중괄호와 정렬하며 멤버는 4칸 들여쓴다. 여러 줄 인자도 4칸씩 들여쓴다.
- 람다 기본 캡처는 쓰지 않는다. 실제 사용하는 값·참조·this를 명시한다.
- 핵심 소유권·동시성 계약과 이유를 한국어로 주석에 남긴다.

## 표현식과 소유권

계산·변환·생성·OS 호출을 의미 있는 지역 변수로 분리해 실행 순서와 조건부 실행을 드러낸다.
단순 조회, 명시적 캐스트, `std::move`, 생성자 초기화·Objective-C alloc/init 관례는 필요에 맞게 유지한다.
불필요한 변수·스코프·복사·수명 연장을 늘리는 기계적 분리는 하지 않는다.
함수 호출이 들어가거나 중첩된 삼항 연산자는 if/else로 푸는 것을 우선한다.

소모용 비자명 인자는 구체 타입 `T&&`를 검토하되, lvalue 복사와 rvalue 이동을 모두 지원해야 하는
Options 같은 소유값은 값 전달을 유지한다. 텍스트는 `string_view`, 바이너리는 `span<char>`를 기본으로 한다.
뷰를 호출 후 보관하지 않는다. Core Audio가 소유한 읽기 전용 입력과 공통 복사 경계에는
`span<const char>`를 유지한다. const를 줄이기 위한 캐스트·복사·포인터와 길이로의 분해는 하지 않는다.

## const와 constexpr

정확성·수명·외부 API·내부 상태 보호 계약을 보존하며 const를 최소화한다. 지역 값 변수·값 매개변수에는
최상위 const를 기본으로 붙이지 않는다. `auto&`가 원본 const를 추론하는 것은 허용한다.
읽기 전용 상태 조회와 복사 금지 선언, 문자열 리터럴, OS 콜백 서명에는 필요한 const를 유지한다.
컴파일 시간 고정값에는 constexpr를 적극 활용한다.

## 리뷰와 검증

먼저 코드의 실행 순서·조건부 실행·RAII·뷰·비동기 버퍼·캡처 수명·락 범위를 검토하고 수정한다.
그 뒤 별도 검증 단계에서 테스트를 실행한다. formatter를 가독성 검토의 대체로 삼지 않는다.

```sh
./scripts/format.sh
./scripts/format.sh --check
```

macOS CLI 프로젝트에 맞춰 셸 스크립트로 formatter를 실행한다.
미구현 기능과 미실행 실기기 검증은 완료로 기록하지 않는다.
